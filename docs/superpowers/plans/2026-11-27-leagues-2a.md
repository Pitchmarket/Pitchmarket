# Private leagues, part 2a (leagues and Classic) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Pro and Ultimate players can create Classic private leagues, anyone can join by invite code, owners manage them, and each league shows a Classic table and a Player of the week worked out from stored weekly scores.

**Architecture:** All league rules live in Postgres (`supabase-leagues-1.sql`): tables with RLS and no direct player writes, SECURITY DEFINER functions for every action and read, and `close_matchweeks()` run by the existing nightly job to store each player's weekly percentage. Membership is stored per stint so history never changes. The page (`index.html`) only calls these functions and renders.

**Tech Stack:** Supabase Postgres (plpgsql, RLS), static `index.html` (vanilla JS, supabase-js 2.118.0), Node 22 nightly script (`backup-data.js`), repo test harness (`tests/run-sql-tests.sh`, `tests/browser/harness.mjs`).

**Spec:** `docs/superpowers/specs/2026-11-27-leagues-design.md` (part 2a only; H2H is 2b, chat 2c)

## Global Constraints

- Creating a league needs Pro or Ultimate (`user_tier(uid) in ('pro','ultimate')`). Joining is free.
- Limits: own up to **3** leagues; be in up to **10**; a league holds up to **20** members.
- Invite code: **6 characters** from `ABCDEFGHJKLMNPQRSTUVWXYZ23456789`; joining ignores case and surrounding spaces. Kicking regenerates the code.
- League names: trimmed, 1–40 characters.
- In 2a only `classic` leagues can be created; the table allows `classic` and `h2h` so 2b needs no migration. The page shows H2H as "Coming soon".
- Matchweek: Monday 00:00 to Sunday 23:59, UK time. Week score = `round((value at end of Sunday / value at end of previous Sunday − 1) × 100, 2)` from `portfolio_snapshots` (each stamped with the London date of the trading day that just ended); start value 0 → 0.
- A week counts only if the previous Sunday is on or after the season start date (`season_start()` in London). Before a season start exists nothing is scored; pages say "Scoring starts when the new season starts."
- A week is **void** if there are no snapshots at all for its Sunday or for the previous Sunday: no scores, no Player of the week; page text "No result this week (the weekly save didn't run)."
- Who counts in a week: members whose stint started before the matchweek's Monday 00:00 UK and hadn't ended before its Sunday 23:59:59 UK.
- Classic table: `(current value / join value − 1) × 100`; join value = live value at joining, or **2000** (the season-start value) for a stint that began before the season start; rejoining in the same season reuses the season's first stint's join value. Ties share a rank.
- Player of the week: highest week score among members who count that week; ties share it; page shows the latest 5 weeks.
- Owner leaves → ownership passes to the member with the earliest current stint; if nobody is left, the league is deleted. Owner can delete the league.
- Branding (Ultimate owners only, shown only while the owner is on Ultimate): colours `claret #7A1C2E`, `sky #4FA3E0`, `emerald #1F9D60`, `gold #D9A520`, `crimson #C8202C`, `navy #1D3557`, `orange #F28C28`, `purple #6C4AB6`; emblems `ball`, `boot`, `whistle`, `trophy`, `net`, `cones`, `flag`, `gloves`, `shirt`, `star`, `crown`, `bolt` (inline SVG, no club crests).
- Only members see a league; no player email or user id ever reaches the page; player text escaped with `escapeHtml`.
- SQL: one new file `supabase-leagues-1.sql`, safe to run twice, folded identically into `supabase-schema.sql`; must load on top of production as it is after part 1.
- Phones: no sideways scrolling at 320–412 px.

## Review Focus

1. A player kicked or leaving midweek, then the week closes: not in that week's Player of the week; earlier weeks they counted in still show them.
2. A player who leaves and rejoins in the same season: Classic percentage measured from the season's first join value, not reset.
3. The nightly job missing a Monday, then running again: the missed week becomes void, later weeks still score, nothing is scored twice.
4. Two people joining the last free place at the same moment: the league never goes over 20 members.
5. A free player calling `create_league` directly (bypassing the page), or a member calling owner-only functions: refused with a clear message.

RLS on both, no policies (all access through functions).
- Produces functions (all `security definer`, `set search_path = public`, granted to `authenticated` only, raising the quoted messages):
  - `player_value(p_user uuid) returns numeric` (internal; revoked from anon/authenticated).
  - `create_league(p_name text, p_type text) returns bigint`: 'Create leagues with Pro or Ultimate.', 'Only Classic leagues can be created for now.', 'League names are 1–40 characters.', 'You can own up to 3 leagues.', 'You can be in up to 10 leagues.'. Adds the owner as first member.
  - `join_league(p_code text) returns bigint`: 'No league with that code.', "You're already in this league.", 'This league is full (20 players).', 'You can be in up to 10 leagues.'. Locks the league row (`for update`) before counting members. Rejoin in the same season copies `join_value` from that season's first stint.
  - `leave_league(p_league bigint) returns void` (ownership hand-over or delete as in Global Constraints).
  - `kick_member(p_league bigint, p_member bigint /* league_members.id */) returns void`: owner only ('Only the owner can do that.'), can't kick self ('Use Leave or Delete for yourself.'); sets `left_at`, `kicked`, regenerates the code.
  - `delete_league(p_league bigint)`, `rename_league(p_league bigint, p_name text)`, `regenerate_league_code(p_league bigint) returns text`, `set_league_branding(p_league bigint, p_colour text, p_emblem text)` ('League branding comes with Ultimate.' unless owner's tier is ultimate; nulls clear it; unknown keys → 'Pick a colour and emblem from the list.').
  - `my_leagues() returns table(league_id bigint, name text, type text, is_owner boolean, member_count integer, colour text, emblem text)` (colour/emblem null unless the owner is currently on Ultimate).
  - `league_detail(p_league bigint) returns jsonb`: `{id, name, type, is_owner, invite_code /* owner only, else null */, colour, emblem, season_started, members:[{member_id, display_name, tier, is_owner, joined_at}]}`; 'You're not in this league.' for non-members.

### Task 2: Weekly scores, Classic table, Player of the week, nightly job (SQL + backup-data.js)

**Files:**
- Modify: `supabase-leagues-1.sql`, `supabase-schema.sql`, `backup-data.js`
- Test: `tests/sql/leagues-scoring.test.sql`

**Interfaces:**
- Consumes: Task 1 tables and `player_value`, `season_start()`, `portfolio_snapshots`.
- Produces tables: `matchweeks(week_end date primary key /* the Sunday */, season_start timestamptz not null, status text not null check (status in ('scored','void')), closed_at timestamptz not null default now())`; `player_week_scores(week_end date references matchweeks on delete cascade, user_id uuid references auth.users on delete cascade, pct numeric(10,2) not null, primary key (week_end, user_id))`. RLS on, no policies.
- Produces functions:
  - `close_matchweeks() returns integer`: closes, in date order, every not-yet-closed week whose Sunday is before today's London date and whose previous Sunday is on or after the season start date; `scored` if both Sundays have snapshots (any rows), writing a score for every user with both snapshots; otherwise `void`. Returns weeks closed. Nothing when no season start. Idempotent. `service_role` only.
  - `league_classic_table(p_league bigint) returns table(rank integer, member_id bigint, display_name text, tier text, pct numeric)` — current members only; empty before a season start; members only.
  - `league_player_of_week(p_league bigint, p_limit integer default 5) returns table(week_end date, status text, winners text[] /* display names */, pct numeric)` — latest `p_limit` closed weeks of the current season, applying "who counts in a week"; members only.
- `backup-data.js`: after the snapshot call, `supabase.rpc('close_matchweeks')`, log `Matchweeks closed: N.`; an error is logged and the backup continues.
- The nightly job runs Monday ~03:23 UTC, so Sunday's snapshot exists when Monday's run closes the week.
